# ЖКХ Digital — Цифровая платформа управления услугами ЖКХ

Полнофункциональная система для управления услугами жилищно-коммунального хозяйства с веб-интерфейсом для жителей, администраторов, технических специалистов и поставщиков услуг.

---

## 📋 Описание системы

ЖКХ Digital — это современная цифровая платформа, которая автоматизирует все процессы управления многоквартирным домом:

- **Передача показаний счётчиков** с фотофиксацией
- **Автоматическое начисление** счетов за услуги
- **Онлайн оплата** с интеграцией платёжных систем
- **Создание и отслеживание заявок** на ремонт и обслуживание
- **Уведомления** о важных событиях (отключения, собрания, платежи)
- **Аналитика и отчёты** для администраторов
- **Многоязычность** (русский, казахский, английский)
- **Адаптивный дизайн** для мобильных устройств

## 🚀 Быстрый запуск

### Требования
- Node.js 18+ 
- MongoDB (для продакшена)
- npm или yarn

### Установка

```bash
# 1. Установить зависимости
npm install

# 2. Скопировать файл конфигурации
cp .env.example .env
# Открыть .env и установить JWT_SECRET

# 3. Заполнить базу тестовыми данными
npm run seed

# 4. Запустить сервер
npm run dev

# Открыть в браузере:
http://localhost:3000/html/login.html
```

### ⚠️ Использование аккаунтов из базы данных

Система поддерживает два формата паролей:
- **Захешированные пароли** (bcrypt) - безопасный формат, используется по умолчанию
- **Открытый текст** - для прямого добавления аккаунтов в базу данных

**Важно:** Использование открытых паролей небезопасно для продакшена. Рекомендуется использовать захешированные пароли.

При добавлении пользователя напрямую в MongoDB, пароль можно сохранить в открытом виде:
```javascript
{
  email: "user@example.com",
  password: "mypassword",  // открытый текст
  role: "resident"
}
```

Система автоматически определит формат и проверит пароль соответствующим образом.

### Для жителей
- **Личный кабинет** — обзор баланса, быстрые действия

### Для технических специалистов

## 🔧 Техническая информация

### Стек технологий
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Authentication:** JWT
- **Frontend:** HTML, CSS, JavaScript
- **File Upload:** Multer

### Структура проекта
```
jkh-digital-full/
├── public/              ← Frontend (статические файлы)
│   ├── html/            ← HTML страницы
│   ├── css/             ← Стили
│   └── js/              ← JavaScript (API клиент, i18n)
├── src/                 ← Backend
│   ├── controllers/     Контроллеры
│   ├── services/        Сервисы
│   ├── middleware/      Middleware
│   ├── routes/          Маршруты API
│   └── data/            Доступ к данным
├── uploads/             ← Загруженные файлы
├── .env                 ← Конфигурация
└── package.json         ← Зависимости
```

### API эндпоинты
Все API запросы к `/api/v1/*` требуют авторизации:
```
Authorization: Bearer <token>
```

Основные эндпоинты:
- `/auth/*` — авторизация и профиль
- `/meters/*` — показания счётчиков
- `/billing/*` — счета и начисления
- `/payments/*` — платежи
- `/requests/*` — заявки на ремонт
- `/news/*` — новости
- `/notifications/*` — уведомления
- `/reports/*` — отчёты (админ)
